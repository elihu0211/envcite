# 分詞器選型的量測紀錄

這是一次**時點量測**的紀錄，不是會隨語料更新的現況：數字取決於量測當時的語料與機器。要看現在的數字，重跑 `scripts/measure-segmentation.py`。結論與用法見 [`../README.md`](../README.md)。

對四部環境法規（311 條、62,211 字）量過，判準是「法定用語出現時是否被切成完整一個 token」——真值取自法條自己的定義條，不是手標的：

| 分詞器 | 術語完整率 | 速度（CPU，批次） |
|---|---|---|
| jieba 預設 | 50.5% | 672,404 字/秒 |
| CKIP albert-tiny | 52.4% | 31,705 字/秒 |
| CKIP bert-base | 54.7% | 4,275 字/秒 |
| **jieba + 語料自產詞典** | **98.9%** | 690,038 字/秒 |

**通用分詞器之間差 4 個百分點，詞典差 44 個百分點。** CKIP 切得比 jieba 合理（`事業/廢棄物` vs `指事/業廢棄物`），但對我們仍是錯的——「事業廢棄物」是一個法定概念，切開就讓查它的人配到講「一般廢棄物」的條文。神經網路不知道哪些詞是立法者定義的。

而 `CkipWordSegmenter` **不接受自訂詞典**，所以那 44 個百分點在那條路上拿不到。

重跑：`scripts/measure-segmentation.py`（取語料用 `scripts/fetch-corpus.sh`）。
