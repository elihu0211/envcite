# 分詞器選型的量測方法

分詞器選型的依據與重跑方式。量測結果取決於當時的語料與機器，所以不在文件裡留數字；要看現在的數字，重跑下列腳本。結論與用法見 [`../README.md`](../README.md)；套件在倉庫中的位置見 [`../../AGENTS.md`](../../AGENTS.md)。

## 判準

「法定用語出現時是否被切成完整一個 token」。真值取自法條自己的定義條，不是手標的。

## 比較對象

| 分詞器 | 備註 |
|--------|------|
| jieba 預設 | 通用詞典 |
| CKIP（不同大小的模型） | 切得比 jieba 合理，但不接受自訂詞典 |
| **jieba + 語料自產詞典** | 採用 |

## 結論

- **詞典的影響遠大於分詞器本身的選擇**：通用分詞器之間的差距小，加上語料自產詞典後的差距大得多。
- CKIP 切得比 jieba 合理（`事業/廢棄物` 對 `指事/業廢棄物`），但對本系統仍是錯的——「事業廢棄物」是一個法定概念，切開就讓查它的人配到講「一般廢棄物」的條文。神經網路不知道哪些詞是立法者定義的。
- `CkipWordSegmenter` 不接受自訂詞典，所以詞典帶來的那一大段差距在那條路上拿不到。

## 重跑

取語料用 [`scripts/fetch-corpus.sh`](../scripts/fetch-corpus.sh)，量測用 [`scripts/measure-segmentation.py`](../scripts/measure-segmentation.py)；參數與用法寫在兩支腳本開頭的說明。
