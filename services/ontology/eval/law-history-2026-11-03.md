# 歷史版本的取得與回推匯入：實測（2026-11-03）

拋棄式 PostgreSQL（`pgvector/pgvector:pg18`，本機新容器），只跑 job 入口：`envcite-migrate` → `envcite-sync moj`（只字面臂，不嵌入）→ `envcite-history`。沒有連 staging 或共用資料庫。

## 來源查證（2026-11-03）

| 來源 | 歷史資料 | 條件 | 結論 |
|------|----------|------|------|
| 全國法規資料庫 Open API（`https://law.moj.gov.tw/api/swagger/docs/v1`） | 只有 `/Ch/Law`、`/Ch/Order`、`/En/Law`、`/En/Order` 四個整批端點，皆為現行版本；歷次修正只有沿革文字（`LawHistories`），沒有修正前的條文 | 政府資料開放授權條款第 1 版 | 取不到歷史全文 |

頁面形狀：固定行寬的折行轉錄（行寬因版本而異，64 或 74 個半形寬）；有兩種條號標記（`<b>` 與編輯器產生的 `<strong class=…>`）；版面排不下的條只在 PDF（標題註明「因條文排版無法完整呈現內容」）；已廢止者的現行頁只有公發布日與廢止日期，最後一版列在歷史清單。

## 範圍

- 系統分類樹列出 1,347 筆，其中法律與命令 **470 部**（行政規則與公告不收）；**468 部**以現名與種類唯一對到語料、且現行版本日與語料相同，2 部對不到（語料沒有該編制表；已廢止的同名舊法）。
- 題庫範圍 246 部中 197 部是環境部主管，其餘 49 部（消防法與其子法、經濟部與衛福部的再利用辦法、行政程序法、行政罰法等）**不在這個來源**：它們的版本仍只從首次取得全國法規資料庫快照起累積。

## 轉錄的保真度

以主管機關系統的現行頁對全國法規資料庫的現行文字逐條核對（回推不靠它，量的是折行還原）：

| | 條 | 逐字相同 | 只差字形 | 分項不同 | 文字不同 | 只在 PDF | 頁上沒有 |
|-|----|----------|----------|----------|----------|----------|----------|
| 現行法規 | 5,691 | 5,077 | 316 | 51 | 26 | 31 | 190 |
| 已廢止 | 1,797 | 515 | 94 | 1,052 | 132 | 0 | 4 |

現行法規 94.8% 逐字或只差字形（全半形括號、英數前後空白）。已廢止法規的「分項不同」多是**全國法規資料庫本身**保留了舊轉錄的硬折行，還原後的文字反而沒有。表是修正 `<strong>` 標記之前量的：「頁上沒有」190 條多是這種頁（廢棄物清理法、環境用藥管理法等），修正後全體的「頁上沒有」由 194 條降為 47 條。與較新版本正規化後相同的條，回推沿用較新版本的文字與分項，判不準只發生在改過的條。

## 行政罰法第 5 條的情境

空氣污染防制法在 2010-01-01 與 2026-11-01 逐條解析，第 56、60 條各得到當日有效的文字（2010 年第 60 條為「違反第三十一條第一項各款情形之一者，處新臺幣五千元以上十萬元以下罰鍰…」，今日為「公私場所違反第六條第一項規定者，處新臺幣二萬元以上一百萬元以下罰鍰…」），行為時法與裁處時法可以比較。

## 缺口與替代來源

- **非環境部主管的法律與命令**（題庫 49 部）：沒有開放的歷史全文；替代是立法院法律系統（法律，僅網頁、採連線階段）與行政院公報（命令，民國 94 年起，只刊登變更的條文，須依 02-02 §3 的回推規則）。都未實作。
- **系統內缺版或只有 PDF 的 36 次公布**：立法理由 PDF 有條文對照表，未解析。
- **分段施行**：歷史版本的待確認 3,607 列、命令定施行日 1,041 列，同現行版本的殘留，解除要靠公報的施行命令。

## 重現

```bash
uv run envcite-migrate
uv run envcite-sync moj
uv run envcite-history            # 取得、回推匯入、授權抽取、檢索投影
uv run envcite-history import     # 再跑：不抓網頁，0 列新增
```

本次 rebase 到最新 main 之後只搬了 HTTP 客戶端（`acquire/web.py`，與函釋共用）並把遷移改號為 0049，回推與寫入的程式不變，未重跑實測。
