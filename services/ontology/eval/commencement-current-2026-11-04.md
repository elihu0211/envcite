# 現行版本的施行日推導：末條的施行日只屬觸及它的公布（2026-11-04）

拋棄式 PostgreSQL（`pgvector/pgvector:pg18`，本機新容器），只跑 job 入口；沒有連 staging 或共用資料庫。

## 問題與修正

`commencement.derive` 在最後一次公布的沿革沒寫施行時，退回讀末條。末條沒被這次公布觸及時，它寫的「自某日施行」是**較早一次公布**的施行日：部分修正的條因此得到一個早於修正公布日、甚至早於上一版的起點。MR !324 只在歷史版本事後把「起點早於版本日」的單元改為待確認，現行版本沒有處理。

改為在推導處判斷：末條**不在最後一次公布所觸及的條裡**時，它寫的特定日期不作這一版的施行日，觸及的條待確認，記 `stale_last_article`（warning）。「自公布日施行」「施行日期由命令定之」不帶日期，對其後每次公布都成立，照舊。沿革語句或被觸及的末條寫的日期（含溯及既往）照寫。`law.PARSER_VERSION` 1 → 2，已匯入的法規以新版重寫。

歷史版本的回推（`ingest/backfill.py`）改用同一條規則，拿掉「起點早於版本日即待確認」的事後檢查：那個檢查把該版沿革自己寫明的溯及施行日也改成了待確認。

## 全庫比對（現行版本，`envcite-sync moj`）

先以 main 的解析器（版本 1）跑 `envcite-migrate` → `envcite-sync moj`（只字面臂），再以本分支（版本 2）跑一次 `envcite-sync moj`，比對同一資料庫裡被取代的列與現行列。資料日 2026-10-22（法律 1,351 部、命令 11,803 部）。

| | 版本 1 | 版本 2 |
|-|--------|--------|
| 重寫的法規 | — | 法律 4、命令 58（`refreshed`），其餘 13,092 部不變 |
| `stale_last_article` | — | 58 部（法律 4、命令 54） |
| specified 單元 | 97,705 | 97,013（−692） |
| unconfirmed 單元 | 51,120 | 51,812（+692） |
| 生效日待確認的現行條（整批驗收） | 6,328（3.98%） | 6,384（4.01%），上限 8% |
| 起點早於版本日的現行單元 | 24,899（878 部） | 24,207（820 部） |

- 受影響的 692 個單元（58 部、101 條）全部由 `specified` 改為 `unconfirmed`，沒有其他方向的改變；其他規則的單元數不變。
- 第二次跑 `moj` 2 分 11 秒（解析器版本改變，全部重新解析；只寫有差異的 62 部）。
- 剩下的 24,207 個「起點早於版本日」都是該版自己寫明的溯及施行日：法律 171 單元（11 部）、命令 24,036 單元（809 部），全部是 `specified`，取自最後一次公布的沿革語句或被觸及的末條。抽查：新臺幣發行準備監理委員會組織規程（沿革「並自五十年七月二日起施行」）、我國學術或研究機構分配股票予我國創作人申請股票適用緩課所得稅作業辦法（「並自一百零六年十一月二十四日施行」）、組織規程與編制表多以發布前某日施行。

## 歷史版本（`envcite-history`）

同一資料庫接著跑 `envcite-history`（環境部主管法規查詢系統，470 部全數取得、0 隔離，首次取得約 36 分鐘）。

| | MR !324（事後檢查） | 本分支 |
|-|---------------------|--------|
| 歷史版本 | 949 | 945 |
| 條文單元版本 | 82,166 | 82,236 |
| 起點早於版本日改待確認（`start_before_version`） | 17 部 | —（規則拿掉） |
| `stale_last_article` | — | 8 部、11 個版本 |
| 起點不早於下一版、不寫列（`never_in_force`） | 5 部 | 2 部 |
| 起點早於版本日的單元 | 0（全被改成待確認） | 304（6 部） |

這 6 部全是命令、全是該版沿革寫明的溯及施行日（如環境部環境影響評估審查委員會組織規程：「修正發布名稱及全文 11 條；並自一百十二年八月二十二日施行」，版本日 112-09-06），MR !324 把它們改成待確認是錯的。兩次的資料日不同（MR !324 量於 2026-11-03），版本與單元數的差異沒有逐一拆解。

## 重現

```bash
uv run envcite-migrate
uv run envcite-sync moj        # 以 main 跑一次（版本 1），再以本分支跑一次（版本 2）
uv run envcite-history
```
