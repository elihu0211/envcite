# 法律的歷史版本取自立法院法律系統：查證與實測（2026-11-04）

拋棄式 PostgreSQL（`pgvector/pgvector:pg18`，本機新容器），只跑 job 入口：`envcite-migrate` → `envcite-sync moj`（只字面臂）→ `envcite-history moenv` → `envcite-history ly`。沒有連 staging 或共用資料庫。

頁面形狀與取得方式（`acquire/ly_law.py`）：

- 檢索是連線階段式：首頁表單（`action` 帶階段代碼）以 POST 送法名稱；只比法名稱，取同名的「現行法」一筆。結果頁、法律頁與版本頁的連結都帶連線階段代碼，所以版本以「法律編號＋三讀日」識別，快照只存內容部分並拿掉條文內連結的代碼（兩個連線階段實抓陸海空軍刑法，快照雜湊相同）。
- 條文頁沒有折行轉錄的問題：項款以 `<br>` 分行。版本日取立法沿革的**公布日**（條文頁只有三讀日），與全國法規資料庫的沿革對齊。
- 該站只接受 TLS 1.2 與不支援安全重新協商的舊式握手（OpenSSL 3 預設拒絕：`UNSAFE_LEGACY_RENEGOTIATION_DISABLED`），共用的 `acquire/web.py` 加 `legacy_tls`（只開 `OP_LEGACY_SERVER_CONNECT`，憑證照常驗證）與 POST 表單。

## 設計

- **一部法規只有一個來源，依種類分**：法律 ← 立法院（`text_authority = legislature`，遷移 0050），命令 ← 主管機關系統（環境部，`competent_authority`）。主管機關系統不再收法律；它以前寫過的法律歷史，由立法院以同日的版本列接手（改記來源、條文依立法院的文字）。
- `envcite-history <ly|moenv> [sync|acquire|import]`：來源（`history_sources.py`）只負責列目標、抓一部、對到語料；回推（`ingest/backfill.py`）兩個來源共用。
- 回推的三個修正（兩個來源都受益）：
  - **未修正以同一來源的相鄰版本判斷**：兩個系統的同一條常差標點或字形（「，」與「；」、「椿」與「樁」、「︰」與「：」）。立法院現行版與全國法規資料庫逐條比，1,361 條（3.6%）有這類差異；以跨系統的文字判斷會把它們當成修正，把立法院的字形寫進歷史版本。
  - **來源落後於語料仍可回推**：立法院尚未收最新一次修正時（14 部），錨點之前的版本照樣回推，記 `source_behind`；來源有語料沒有的較新版本才是 `current_date_mismatch`。
  - **同日公布的數版取後通過的一版**：分別三讀、同日公布的兩版是累積的（如中華民國刑法 2020-01-15：先通過的版本改第 149、150 條，後通過的再改第 251、313 條且保留前者）。

## 題庫與行政罰法第 5 條

- **題庫 246 部**：歷史完整 207 → **210 部**（行政程序法、行政罰法、消防法由立法院補齊；原由主管機關系統完整的 13 部法律改由立法院提供，仍完整）。仍沒有任何歷史版本的 27 部全是**其他部會主管的命令**（消防法施行細則與各類消防設置標準、經濟部與衛福部等的事業廢棄物再利用辦法），立法院不收命令，這個 MR 補不到。
- **行政罰法第 5 條**：立法院有 94、100、111 年三版；2012-01-01 解析得 100 年版「適用行政機關最初裁處時之法律或自治條例」，2026-11-01 得 111 年版「適用裁處時之法律或自治條例」，行為時法與裁處時法可以比較。2010-01-01 是「生效日待確認」：94 年版末條「本法自公布後一年施行」是相對期間，推導不猜（02-03 §6）。

## 缺口與後續

- **施行命令被判成修正**（`history.classify`）：沿革裡「司法院令發布第 51-5～51-8 條條文定自…施行」「行政院令發布：本次修正條文，定自…施行」這類施行命令，因含「發布第…條條文」或「修正」被判成部分修正，回推要求那天有一個版本而停下（立法院 29 處）。修正會改變現行版本的事件與施行日推導，要遞增 `PARSER_VERSION`，另開 MR。
- **其他部會主管的命令**（題庫 27 部）：唯一的官方歷史全文是行政院公報（民國 94 年起，只刊變更的條文，須依 02-02 §3 的回推規則）。
- 民法（分編命名）與用字不同的名稱（羣／群）要有名稱對照才對得到。

## 重現

```bash
uv run envcite-migrate
uv run envcite-sync moj
uv run envcite-history moenv
uv run envcite-history ly          # 首次約 2.5 小時（每頁 1 秒），之後每次約 2 小時（每部 3 頁）
uv run envcite-history ly import   # 再跑：不抓網頁，0 列新增
```
